# 🏋️ Fitness App

Aplicación móvil de fitness desarrollada en **Kotlin** como proyecto de clase. Se trabaja en ella día a día, incorporando nuevos conocimientos y funcionalidades conforme avanzamos en el aprendizaje.

## 🛠️ Tecnologías utilizadas

- Kotlin
- Android Studio
- Jetpack Compose
- Android SDK

## 📱 Estado actual

Actualmente contamos con dos pantallas y la posibilidad de consultar y modificar los datos del perfil de usuario.

## 🚧 En desarrollo

Este proyecto se irá actualizando progresivamente conforme avancemos en clase, añadiendo nuevas pantallas, funcionalidades y mejoras.
